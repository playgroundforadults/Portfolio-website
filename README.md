# Personal Portfolio Website

## Project Overview

This is a single-page responsive portfolio website created as part of a lab assignment. The website showcases personal information, projects, skills, and contact details. It is built using **HTML**, and **CSS**.

- URL Link to website portfolio: [Click Here](https://playgroundforadults.github.io/Portfolio-website)
- URL Link to website design: [Click Here](https://www.canva.com/design/DAG3T3HWQ7g/68I5vgMDDcyTtDwAzfmLQA/edit?utm_content=DAG3T3HWQ7g&utm_campaign=designshare&utm_medium=link2&utm_source=sharebutton)

## Purpose

The goal of this project is to improve my website making skills in ensuring it is responsive and usable on any device

## Target Audience

This portfolio is intended to be viewed by potential employers

## Technologies Used

- HTML5
- CSS3 (Flexbox, Box Models, Media Queries)

## Layout & Sections

The website includes the following sections:

- **Header**
- **About Me**
- **Projects**
- **Skills**
- **Contact**
- **Footer**

## 📱 Responsiveness

The site is optimized for:

- Desktop
- Tablet
- Mobile

> Responsive design is achieved using media queries and flexible layouts.

## 🧪 How to Run Locally

1. Open your code editor (e.g., Visual Studio Code, etc.).
2. In your code editor, open the terminal.
3. Clone the repository:
   ```bash
   git clone https://github.com/your-username/portfolio-website.git
   ```
4. Open index.html in your browser, or run the website locally using the Live Server Extension.
