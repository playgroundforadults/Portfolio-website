# Personal Portfolio Website

## Project Overview

This is a single-page responsive portfolio website created as part of a lab assignment. The website showcases personal information, projects, skills, and contact details. It is built using **HTML**, and **CSS**.

## Purpose

The goal of this project is to improve my website making skills in ensuring it is responsive and usable on any device

## Target Audience

This portfolio is intended to be viewed by potential employers

## Technologies Used

- HTML5
- CSS3 (Flexbox, Box Models, Media Queries)

## Layout & Sections

The website includes the following sections:

- **Header**
- **About Me**
- **Projects**
- **Skills**
- **Contact**
- **Footer**

## Responsiveness

The site is optimized for:

- Desktop
- Tablet
- Mobile

> Responsive design is achieved using media queries and flexible layouts.
